## ✨ Features

- **🚀 Multi-Channel Campaign Studio:** Generates social captions (with hooks, hashtags & CTAs), paid ad copy (Meta & Google ads), and WhatsApp broadcast messages in one pass.
- **🎨 Live 1080p Poster & Flyer Studio:** Client-side HTML5 canvas poster builder supporting 1:1 (Square), 9:16 (Story/Status), and 16:9 (Landscape) with 7 vibrant themes and instant PNG/JPEG download.
- **💬 WhatsApp Broadcast Hub:** Compose and preview messages in a realistic phone chat simulator with WhatsApp formatting (`*bold*`, `_italics_`, emojis) and 1-click `wa.me` links.
- **📂 10+ Ready-Made Templates:** Battle-tested templates for payday sales, slow weekday boosters, BOGO offers, VIP customer rewards, and flash clearances.
- **🏬 Industry Presets:** Tailored copy models for Restaurants & Cafes, Salons & Spas, Boutiques & Retail, Gyms & Fitness, Trades & Home Services, Automotive, Real Estate, and more.
- **💎 Free vs Paid Upgrade Tiers:**
  - **Starter Pilot (Free):** 5 AI generations/month, standard templates.
  - **Pro Pilot (R99/month):** 60 AI generations/month, watermark-free HD poster exports, WhatsApp broadcast suite.
  - **Growth Pilot (R249/month):** Unlimited generations, 4K print-ready exports, custom brand kit.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide React, Motion
- **Backend:** Express, Node.js (Full-stack dev server via Vite middleware)
- **AI Engine:** Google Gemini API (`@google/genai` with `gemini-3.8-flash`)
- **Canvas Rendering:** HTML5 2D Canvas with crisp device pixel ratio scaling

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/promopilot.git
cd promopilot
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment variables
Create a `.env` file based on `.env.example`:
```env
GEMINI_API_KEY="your-google-gemini-api-key"
PORT=3000
```

### 4. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
